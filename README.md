# astro

> A curated collection of wallpapers updated every month!

## 📁 Repository Structure

### 🖥️ Desktop Wallpapers (`Desktop/`)

- **`Anime-and-Pixel-Art/`**
  - Cozy lo-fi aesthetics, pixel art cityscapes, and anime scenes.
- **`Developer-and-Tech/`**
  - Minimalist coding themes, terminal cubes, VS Code, Gruvbox console, and developer glyphs.
- **`Minimal-and-Abstract/`**
  - Topographic wave contours, monochrome cards, and glassmorphic designs.
- **`Nature-and-Landscape/`**
  - Scenic snowy mountain lakes, Firewatch lookout towers, and moody rainy streets.

### 📱 Phone Wallpapers (`Phone/`)

- **`Abstract/`**
  - Glassmorphic glowing pills, frosted dock widgets, and Nothing-inspired textured glass designs.
- **`City-and-Landscape/`**
  - Sci-fi megastructure canyons, moody misty skylines, and sunset pixel scenes.
- **`Minimal/`**
  - Clean monochrome gradient stacks, Nothing OS glyph dot-matrix layouts, and horizon sunsets.
